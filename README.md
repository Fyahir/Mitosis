# Deep Learning for Mitosis Cell Damage Classification

Este repositorio contiene la implementación y notebook de desarrollo de un modelo de Deep Learning enfocado en la clasificación de fases y daño celular en mitosis a partir de imágenes microscópicas.

## 🚀 Tecnologías utilizadas
* **Python**
* **TensorFlow / Keras** (Modelos de clasificación)
* **OpenCV / NumPy** (Preprocesamiento y manipulación de imágenes)
* **Scikit-learn** (Evaluación de métricas y matrices de confusión)

## 📌 Características del proyecto
* Preprocesamiento y normalización de imágenes microscopicas.
* Entrenamiento y ajuste de arquitecturas de Redes Neuronales Convolucionales (CNN / EfficientNet).
* Evaluación del rendimiento
